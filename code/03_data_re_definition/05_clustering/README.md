# 05 - Clustering Analysis of Leaf Morphological Traits

Clustering and similarity analysis of extracted leaf morphological traits across *Arabidopsis thaliana* accessions, organized into two datasets.

## Traits Measured

| Trait | Type | Preprocessing |
|---|---|---|
| Petiole Length | Categorical | Mode (preprocessing) / Label Encoded (trees) |
| Leaf Margin | Categorical | Mode (preprocessing) / Label Encoded (trees) |
| Leaf Shape | Categorical | Mode (preprocessing) / Label Encoded (trees) |
| Number of Leafs | Numerical | Discretized into Low / Medium / High (3 bins, uniform strategy) |

## Datasets

### LTU-1

- **25 accessions**
- Dissimilarity analysis computed for all combinations of **5** accessions (53,130 combinations)

### LTU-2

- **8 accessions**: Kz-9, TOU-I-17, Cvi-0, Zdr-1, Is-1, Col-0, Ler-1, Uk-1
- Dissimilarity analysis computed for combinations of **4** (70 combinations) and **5** (56 combinations) accessions

## Notebooks

### `preprocessing.ipynb`

Builds a summarized traits matrix and computes pairwise similarity/dissimilarity across accessions.

1. **Data loading** -- Reads per-accession Excel files containing replicate-level measurements
2. **Discretization** -- Bins `Number of Leafs` into 3 ordinal categories (Low, Medium, High) using `KBinsDiscretizer` (uniform strategy)
3. **Aggregation** -- Computes the mode of each trait per accession to produce a single representative row
4. **Traits matrix** -- Assembles all accessions into a summary table and exports to `traits_matrix.csv`
5. **Similarity matrix** -- Calculates pairwise Simple Matching Coefficient (proportion of matching traits) and exports to `similarity_matrix.csv`
6. **Dissimilarity ranking** -- Evaluates all k-combinations of accessions, ranking them by average dissimilarity (1 - mean pairwise similarity), exported to `dissimilarity_*.csv`

### `trees.ipynb`

Performs hierarchical clustering within each accession (across replicates) and computes per-accession similarity matrices.

1. **Data loading** -- Reads per-accession Excel files
2. **Label encoding** -- Encodes categorical traits (Petiole Length, Leaf Margin, Leaf Shape) as integers using `LabelEncoder`
3. **Hierarchical clustering** -- Agglomerative clustering with complete linkage and Euclidean distance, generating a dendrogram per accession saved as `tree.pdf`
4. **Similarity matrix** -- Computes per-accession Simple Matching Coefficient matrix across replicates and exports to `similarity_matrix.csv`

## Outputs

| File | Description |
|---|---|
| `traits_matrix.csv` | Mode-summarized trait values per accession |
| `similarity_matrix.csv` | Pairwise Simple Matching Coefficient matrix |
| `dissimilarity_4.csv` | Dissimilarity scores for all 4-accession combinations (LTU-2 only) |
| `dissimilarity_5.csv` | Dissimilarity scores for all 5-accession combinations |
| `tree.pdf` | Dendrogram per accession (generated by `trees.ipynb`) |
