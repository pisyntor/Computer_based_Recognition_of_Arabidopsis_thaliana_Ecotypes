Readme Notes


Please note that, depending on your antivirus settings, a warning may appear when launching the installer or the application itself. It may claim that the application is dangerous and could potentially harm your computer. In some cases, the installer or the application may be completely blocked from running.


This behavior is expected, as the app is currently not digitally signed. For security reasons, please scan all application files before launching them for the first time. If no threats are detected, you may safely ignore any warnings and proceed to launch the app. If warnings persist, click the appropriate buttons in the warning pop-ups to allow the app to run.


Finally, this app may not run properly on your own data due to several factors: it is still a prototype; it may have been developed using data that differs significantly from yours; and your data may have a structure that does not match the format expected by the app.
